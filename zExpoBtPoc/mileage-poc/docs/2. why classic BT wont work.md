## ✅ 3. The real solution: iOS does expose car connection events — just not via Bluetooth

iOS exposes car connection state through two other subsystems:

### A. CarPlay connection events
When CarPlay connects:
- iOS fires a CarPlay connection event
- The phone switches networks
- The car’s Classic Bluetooth connection is active
- The system knows you’re in a vehicle

React Native can detect this indirectly via:
- Network change events
- Audio route changes
- External accessory notifications (if supported)

### B. Audio route changes (AVAudioSession)
When your phone connects to a car:
- The audio route changes to “Car Audio”
- This is detectable in React Native
- It works even if CarPlay is disabled
- It works even if the car uses Classic Bluetooth only

This is the most reliable signal for your app.
